# Profile

Copy this to `profile.md` and fill it in. Every prompt in `prompts/` reads this file, so it
replaces the `[insert your skill]` blank the source thread makes you paste six separate times.

Be specific. "Experienced engineer" produces generic outreach that gets ignored. "Shipped the
billing rewrite that cut failed payments 30%" produces outreach that gets a reply. If a section
doesn't apply, write `n/a` rather than deleting it — the prompts check for these headings.

Three to six accomplishments, each with a number if you can get one. This is the raw material
for every piece of outreach and every resume bullet the kit generates. Format:

- **[What you did]** — [context: company, team size, constraint] → [outcome, quantified]
