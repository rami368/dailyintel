# DAILY INTEL — Brand Assets

## PowerPoint template

`DAILY-INTEL-template.pptx` — a 9-slide 16:9 deck template built from the app's design system (`index.html`). Layouts included: title, agenda, section divider, two-column narrative + callout, stat tiles, chart, ticker spotlight (stock-card layout), process/timeline, and closing with disclaimer. Replace the placeholder copy and duplicate whichever layouts you need.

## Design tokens (from `index.html`)

|---|---|---|
| Background | `#06080C` | Slide background |

Signature element: the 135° green → blue gradient (logo chip, badges, progress bar).

## Typography

- **JetBrains Mono** — headings, data, uppercase letter-spaced labels
- **Space Grotesk** — body copy

Both are free Google Fonts. Install them locally for full fidelity; PowerPoint falls back to system fonts otherwise.
